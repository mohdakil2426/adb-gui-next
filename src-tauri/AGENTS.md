# Rust backend module guide

`src-tauri/` owns the Tauri host: plugins, thin commands, domain modules, helpers, permissions, and bundled platform-tools. Frontend must reach this only via IPC.

## Read first

- Root `AGENTS.md`, `docs/architecture.md`, `docs/project_rules.md`.
- `src/AGENTS.md` when changing the IPC contract (keep FE desktop layer + models in sync).

## Ownership

| Area | Primary path |
| --- | --- |
| Bootstrap / handler list | `src/lib.rs` |
| Thin commands | `src/commands/*.rs` |
| Shared process/path helpers | `src/helpers.rs` |
| Payload domain | `src/payload/` |
| Marketplace domain | `src/marketplace/` |
| Emulator domain | `src/emulator/` |
| Debloat domain | `src/debloat/` |
| ACL | `capabilities/default.json`, `permissions/autogenerated.toml` |
| Bundled adb/fastboot | `resources/{windows,linux}/` |

## Module invariants

- Commands return `CmdResult<T> = Result<T, String>` unless a documented exception exists.
- Long-running / blocking work: `async` + `spawn_blocking` or `block_in_place` as appropriate.
- **Thin commands** — real logic in domain modules or `helpers.rs`.
- IPC structs: `Serialize` + `#[serde(rename_all = "camelCase")]`. Tagged enums rename tag **values** too.
- `resolve_binary_path()` for bundled ADB/fastboot. Emulator binary is **not** bundled — SDK resolver.
- Critical shell ops: `helpers::adb_shell_checked` (host OK ≠ shell OK).
- Filenames: `sanitize_filename` / `safe_image_file_name` before joining user or manifest names.
- Remote HTTP: no auto-follow redirects; `validate_outbound_url` every hop (payload + marketplace + Magisk).
- Debloat: device-serial-keyed cache; refuse destructive actions when SDK unknown; no Disable on API &lt; 23.
- Permissions: every `generate_handler!` command in `permissions/autogenerated.toml` `commands.allow` (no orphans).
- Payload: streaming/mmap; invalid cancel token = error; `TransactionGuard` deletes registered files only (never `remove_dir_all` on user output dirs).
- Marketplace install: selected serial + owned temp download path only.
- Emulator AVD discovery: `~/.android/avd/*.ini` (not `emulator -list-avds`). Root proof: `verify_avd_root` / `su -c id -u == 0`.
- Clippy bar: package `[lints]` + `clippy.toml`; CI uses `-D warnings`.

## Validation

| Change type | Minimum gate |
| --- | --- |
| Docs only | `git diff --check` |
| Rust code | `bun run format:rust:check`, `bun run lint:rust`, targeted `cargo test --manifest-path src-tauri/Cargo.toml` when practical |
| IPC contract | Also FE `backend.ts` / `models.ts` + permission allowlist |
