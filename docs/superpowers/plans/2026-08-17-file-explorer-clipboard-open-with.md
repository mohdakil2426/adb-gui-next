# File Explorer Clipboard, Open With, and Shortcuts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add same-device copy/cut/paste/move, Open with (VS Code / Notepad / host folder) plus push-on-save, and the remaining Windows-like File Explorer shortcuts.

**Architecture:** Device mutations stay in `src-tauri/src/commands/files.rs` as thin commands over `run_shell_for_mode` / existing pull-push. The FE owns a session clipboard and editor-watch toasts via `src/desktop/backend.ts` + `EventsOn('files:edit-pushed')`. No OS file clipboard. No new crates: watch by polling mtime+hash.

**Tech Stack:** React 19, TypeScript, Vitest, Tauri 2, Rust 2024, existing AlertDialog / context-menu / shortcut help.

**Spec:** `docs/superpowers/specs/2026-08-17-file-explorer-clipboard-and-open-with.md`

```ts
import { getFileName } from '@/shared/utils/filePath';

export function joinRemoteDir(dir: string, name: string): string {
  const trimmed = dir.trim();
  const base = trimmed === '/' ? '' : trimmed.replace(/\/+$/, '');
  return `${base}/${name}`;

export function destinationPath(destDir: string, sourcePath: string): string {
  return joinRemoteDir(destDir, getFileName(sourcePath.replace(/\/+$/, '')));
}
```

```rust
    pub sources: Vec<String>,
    pub dest_dir: String,
    pub overwrite: bool,
    pub serial: Option<String>,
    pub access_mode: Option<FileAccessMode>,
}

    pub skipped_existing: Vec<String>,

```

Commands: `copy_device_files`, `move_device_files`.

Logic (both):
1. Reject empty `sources`.
2. Validate dest + every source.
3. Build dest paths; if dest equals source, skip that item.
4. Probe existence with `test -e` **without** `shell_checked` — use `AdbClient::shell` / `run_adb_for_serial` so exit 1 means missing. Prefer: `run_shell_for_mode` is wrong for test -e. Use `AdbClient::new(&app, serial).shell(&format!("test -e {} && echo exists || echo missing", quote_shell_arg(&dest)))` and look for `exists` / `missing`.
5. If any `exists` and `!overwrite`, return `Ok(DeviceTransferResult { transferred: vec![], skipped_existing })` **without** mutating.
6. Else run `cp -a {src} {dest_dir_quoted}` for copy (dest_dir must exist as directory) or `mv {src} {dest}` for move. Use dest **directory** for `cp -a src dest_dir/` so toybox copies into the folder. For overwrite, `rm -rf dest_file` then copy/move.
7. Cut/move: `mv src dest_path`.
