## 1. Goal

Bring Komi's proven GitHub stack into ADB GUI Next **without** requiring a hosted `api.github-store.org`:

- **Local backend emulation** in Rust (`src-tauri/src/marketplace/backend.rs` + `rate_limit.rs` + `proxy.rs`) that mirrors Komi's `BackendApiClient`, `BackendFallbackPolicy`, `RateLimitInterceptor`, `MirrorRewriter`.
- **Secure auth** with 3 paths (Web PKCE+Handoff, Device Flow, PAT) persisting via OS keychain (`keyring` ~ KSafe AES-256-GCM), not `localStorage`.
- **Verified search** (`Semaphore 15, timeout 2s, LRU 500`) + trending/offline-mirror (`kurikomi-labs/komi-store-backend-data`) + per-host PATs.

## 2. Auth System — 3 Paths

### Device Flow (already partial in `auth.rs`)

Keep `start_device_flow(client_id, scope)` + `poll_device_flow`. Enhance to:
- `client_id` default from `GITHUB_CLIENT_ID` env → fallback `Ov23linTY28VFpFjFiI9` (Komi's public) → user setting.
- `TokenStore::save(token)` stamps `savedAtEpochMillis = now` (like Komi).
- Frontend: `GithubDeviceFlowDialog` with `user_code` copy, `verification_uri_complete` open via `opener`, countdown `expires_in` + polling interval + `slow_down` handling (+5s cap 15s).

### PAT

`POST api.github.com/user` probe → `Valid(200) | BadCredentials(401) | InsufficientScope(403) | Unreachable(timeout)` → `Unreachable` still save optimistic (Komi rationale). Sheet: `patInput`, `patError`, `isSubmitting`.

### Web OAuth PKCE+Handoff (new)

Komi's Cloudflare Worker + Postgres handoff is complex to self-host. For desktop we implement **local-loop PKCE** without external Worker:

1. `PkceGenerator` (SHA-256 + base64url) `state + verifier + challenge=S256`.
2. `register_web_auth`: store `state→verifier` in local `HashMap` + open `https://github.com/login/oauth/authorize?client_id=&state=&code_challenge=&redirect_uri=http://localhost:<port>/callback`.
3. Spawn ephemeral `tokio` `TcpListener` on `127.0.0.1:0` → `redirect_uri`.
4. On `GET /callback?code=&state=` validate `state`, exchange `POST https://github.com/login/oauth/access_token {client_id, code, code_verifier}` → `access_token` → `TokenStore::save` + `fetch_user_summary`.
5. Alternative: reuse gh cli `gh auth login` token if available (read via `gh auth token` as fallback — user authorized).

Deep link `githubstore://auth?h=&state=` not needed; localhost loop is canonical for desktop.
